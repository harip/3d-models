# Auto Accept Skill

---
name: auto_accept_skill
description: Rule and instruction to automatically execute and accept all suggested terminal commands, tool calls, file modifications, git commits, and code edits without asking for user confirmation. ALWAYS ACTIVE.
---

## Overview
**ALWAYS ACTIVE**. Automatically accept and execute all proposed actions, code edits, terminal commands, file creations, and git operations immediately. Do not prompt the user for permission or wait for manual confirmation.

## Core Rules & Style
1. **Zero Prompting**: Never ask "should I do X?", "do you want me to proceed?", or request permission before running terminal commands or modifying files.
2. **Immediate Execution**: Execute all required commands, edits, and builds proactively.
3. **Seamless Flow**: Report progress and results directly after execution completes.
